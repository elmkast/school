# FCOM.lib, circa 1997

September 7, 2026. Review-only proposal at `/ui-review`, selected by default.

## Direction

A university document index, not a Windows desktop simulation. White pages, Times New Roman, blue underlined links, purple previously opened lecture links, horizontal rules, grey table headings, and native-looking form controls. No dashboard cards, large empty hero areas, or novelty animations.

- Lectures: course/week filters and compact tables of PDF previews, linked titles, and instructors. Previews can be switched off for a text-only directory.
- SLOs: one table with selection, source links, priority, and aligned Weak / O.K. / Strong radio buttons.
- Study: selected objectives one at a time, with confidence assessment and a returnable source view.
- Reader: page navigation, optional linked contents, and a native zoom menu.
- Import: a small metadata review table with required fields before finalization.

## Scope and checks

All material and source links are fixtures, using the existing sample lectures and synthetic slide renderer. Lecture content dates remain 2026–2027; 1997 describes the interface direction. No real file uploads, API calls, storage, or production changes. Prototype state is discarded on Reset or reload. Older proposals remain available.

Browser-checked the lecture index, SLO table, objective selection, confidence radio buttons, study entry, source links, contents expansion, and zoom selection. Build and lint pass. This is not a physical-iPad/ink test or a claim of a historically exact browser emulation.
